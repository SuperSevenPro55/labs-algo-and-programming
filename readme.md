# Сборник лабораторных работ: Алгоритмы и Структуры Данных

Этот репозиторий содержит практические решения лабораторных работ по курсу алгоритмов и структур данных. Проект представляет собой консольное приложение на Java с интерактивным меню для тестирования каждого алгоритма.

## 🧠 Содержимое проекта

Кодовая база разделена на реализацию базовых структур данных и классических алгоритмических задач:

### 1. Структуры данных
* **Priority Queue** — очередь с приоритетом на основе двоичной кучи (Max-Heap).
* **Min Stack** — стек с поддержкой получения минимального элемента.
* **Hash Map** — собственная реализация хеш-таблицы.

### 2. Алгоритмы
* **Сортировки:** слиянием (Merge Sort), поразрядная (Radix Sort), подсчетом (Counting Sort) и вставками (Insertion Sort).
* **Поиск:** бинарный поиск и префиксные суммы.
* **Динамическое программирование:** поиск наибольшей возрастающей подпоследовательности (LIS) и наибольшей общей подпоследовательности (LCS).

## 🧰 Стек технологий
* **Язык:** Java 21
* **Сборка:** Maven
* **Тестирование:** JUnit 5
